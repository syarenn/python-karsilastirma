# Python Karşılaştırma Programı

## Proje ne yapıyor?
Bu proje, kullanıcıdan iki sayı alır ve bu sayıları karşılaştırır. Hangi sayının daha büyük olduğunu belirler. Eğer iki sayı eşitse bunu kullanıcıya bildirir.

## Proje neden faydalı?
Bu proje, Python programlama dilindeki temel yapıları öğrenmek için faydalıdır. Kullanıcıdan veri alma, sayısal dönüşüm yapma ve koşullu ifadeleri kullanma konularını öğretir.

## Kullanıcılar projeyi nasıl çalıştırabilir?
1. `karsilastirma.py` dosyasını indirin.
2. Dosyayı Python IDLE ile açın.
3. Programı çalıştırın.
4. İstenilen iki sayıyı girin.
5. Program karşılaştırma sonucunu ekranda gösterecektir.
6. 'Enter'a' basarak projeden çıkın.

## Kullanıcılar nasıl yardım alabilir?
Projeyle ilgili bir sorun yaşanırsa GitHub üzerinden Issue oluşturularak yardım istenebilir.

## Projeyi kim sürdürüyor ve katkı sağlıyor?
Bu proje, yükleyen kişi tarafından geliştirilmekte ve sürdürülmektedir.
